# Cars Dealership

A full-stack dealership directory and review application for the Full-stack Development Capstone. The intended application lets visitors browse U.S. dealership branches, filter dealers by state, register and log in, view dealer reviews, submit reviews, and analyze review sentiment.

## Project status
